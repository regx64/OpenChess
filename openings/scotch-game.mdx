## 개요

스카치 게임은 1824년 에든버러와 런던의 통신 대국에서 이름을 얻었습니다. 백은 루이 로페즈처럼 천천히 압박하지 않고 `3. d4`로 바로 중앙을 엽니다. 이론이 비교적 적고 계획이 명확해 실전적이며, 카스파로프가 1990년대에 다시 유행시켰습니다.

## 기본 아이디어

**백**
- 중앙 폰 교환 후 d4의 나이트를 중심으로 빠르게 전개합니다.
- e4 폰으로 공간을 확보하고, 경우에 따라 `e5`로 흑 나이트를 쫓아냅니다.

**흑**
- d4 나이트를 교환하거나 `...Bc5`, `...Nf6`로 빠르게 반격합니다.
- 중앙이 열려 있으므로 기물 활동성으로 균형을 맞춥니다.

## 주요 변형

### 클래시컬 변형 (4...Bc5)

수순: `1. e4 e5 2. Nf3 Nc6 3. d4 exd4 4. Nxd4 Bc5`

흑이 비숍으로 d4 나이트를 바로 압박합니다. 백은 `5. Be3`이나 `5. Nxc6`, `5. Nb3`으로 대응합니다.

### 슈미트 변형 (4...Nf6)

수순: `1. e4 e5 2. Nf3 Nc6 3. d4 exd4 4. Nxd4 Nf6 5. Nxc6 bxc6 6. e5`

가장 날카로운 메인 라인입니다. 백이 `e5`로 나이트를 쫓고, 흑은 `6...Qe7`으로 e5 폰을 압박하는 독특한 형태가 됩니다.

### 스카치 갬빗

수순: `1. e4 e5 2. Nf3 Nc6 3. d4 exd4 4. Bc4`

백이 d4 폰을 바로 되찾지 않고 비숍을 전개해 공격을 노립니다. 흑이 `4...Nf6`로 응수하면 투 나이츠 디펜스와 비슷한 형태로 이어질 수 있습니다.

## 주의할 점

- `4...Qh4`(스타인리츠 변형)는 e4 폰을 노리는 공격적인 수입니다. 백은 `5. Nb5`나 `5. Nc3`으로 정확하게 대응해야 합니다.
