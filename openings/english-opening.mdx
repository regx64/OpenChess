## 개요

잉글리시 오프닝은 1843년 하워드 스턴턴이 생타망과의 대결에서 사용한 뒤 이름이 붙었습니다. 백은 `1. c4`로 중앙을 측면에서 통제하고, 대개 `g3`, `Bg2`, `Nc3`으로 긴 대각선을 활용합니다. 보트비닉, 카스파로프, 칼센 등이 즐겨 썼으며 다른 오프닝으로 전환되는 경우도 많습니다.

## 주요 변형

### 리버스드 시실리안 (1...e5)

수순: `1. c4 e5 2. Nc3 Nf6 3. Nf3 Nc6 4. g3`

흑이 `...e5`로 응하면 백은 시실리안 디펜스를 한 수 더 둔 형태가 됩니다. 백은 g2 비숍과 퀸사이드 확장을 노립니다.

### 대칭 변형 (1...c5)

수순: `1. c4 c5 2. Nc3 Nc6 3. g3 g6 4. Bg2 Bg7`

양쪽이 똑같이 피앙케토하는 대칭 구조입니다. 미묘한 수순 차이가 승부를 가릅니다.

### 보트비닉 시스템

수순: `1. c4 e5 2. Nc3 Nc6 3. g3 g6 4. Bg2 Bg7 5. e4`

백이 c4·e4 폰으로 d5 칸을 확실히 장악하는 체계입니다.

### 인디언 계열 (1...Nf6)

수순: `1. c4 Nf6 2. Nc3 e6 3. e4`

흑이 님조인디언·퀸즈 인디언 계열로 대응하면, 백은 `e4`로 전환해 미켄베르그-카로 변형 같은 독자적인 구조를 만들 수 있습니다.
