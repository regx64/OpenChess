## 개요

에피 보골류보프의 이름을 딴 오프닝입니다. 백이 `3. Nf3`으로 님조인디언을 피하면, 흑은 `3...Bb4+`로 체크하며 비숍을 전개합니다. 이론이 비교적 적고 안정적이어서 실전적인 선택지로 꼽힙니다.

## 주요 변형

### 4. Bd2

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Bd2 Qe7`

가장 흔한 대응입니다. 흑은 `...Qe7`으로 비숍을 지키거나 `...Bxd2+`로 교환합니다.

### 4. Nbd2

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Nbd2`

백이 비숍 쌍을 얻을 기회를 노립니다. 흑은 `...b6`, `...d5`, `...O-O` 등으로 유연하게 대응합니다.

## 이런 분께 추천

님조인디언 계열의 구조를 좋아하면서 이론 부담을 줄이고 싶은 흑 플레이어에게 어울립니다.
