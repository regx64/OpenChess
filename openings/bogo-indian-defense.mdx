## 개요

보고인디언 디펜스는 `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+`로 시작하는 오프닝입니다.

`1. d4 Nf6 2. c4 e6` 이후 백의 전통적인 수는 `3. Nc3`으로, `4. e4`로 큰 폰 중앙을 세우겠다고 위협합니다. 하지만 `3. Nc3`에는 흑이 `3...Bb4`로 님조인디언 디펜스를 둘 수 있으므로, 이를 피하려고 `3. Nf3`을 두는 백이 많습니다. 이때 흑은 대개 `3...b6`(퀸즈 인디언)이나 `3...d5`(퀸즈 갬빗 거절로 전환)를 두지만, 님조인디언과 비슷한 정신으로 `3...Bb4+`를 둘 수도 있습니다. 이것이 보고인디언입니다.

데이터베이스 통계로는 퀸즈 인디언의 절반 정도 빈도로 두어집니다. `1. d4 e6 2. c4 Bb4+`(케레스 디펜스)라는 수순으로도 도달할 수 있습니다. ECO 코드는 E11이며, 이름은 20세기 그랜드마스터 에핌 보골류보프의 이름을 줄인 것입니다.

## 역사

러시아 태생의 독일 마스터 에핌 보골류보프가 고안한 것으로 여겨지며, 그는 1920년대에 이 오프닝을 꾸준히 두었습니다. 이후 님조비치, 케레스, 페트로시안, 벤트 라르센, 스미슬로프, 코르치노이, 울프 안데르손, 마이클 애덤스, 니키타 비튜고프 등 많은 강자가 사용했습니다.

## 기본 개념

### 체크의 의미

님조인디언에서는 b4 비숍이 c3 나이트를 핀하지만, 보고인디언에서는 c3에 나이트가 없으므로 체크가 됩니다. 흑은 비숍을 활발하게 전개하면서 빠르게 캐슬링할 준비를 마칩니다. 백은 이 체크를 막는 방법에 따라 성격이 다른 포지션으로 갑니다.

### 흑의 계획

- **검은 칸 장악**: `...Qe7`, `...d6`, `...e5`처럼 검은 칸에 폰을 두어, 비숍을 교환한 뒤에도 구조를 안정시키는 방식이 흔합니다.
- **e4 칸 통제**: `...Ne4`로 백 비숍이나 나이트를 교환하며 공간 부족을 해소합니다.
- **기물 교환**: 공간이 조금 좁은 대신 견고하므로, 적절한 교환으로 무난한 균형을 노립니다.

### 백의 계획

- 대부분의 라인에서 `g3`, `Bg2`로 킹 비숍을 피앙케토해 긴 대각선을 활용합니다.
- 흑이 비숍을 교환하면 비숍 쌍이 아니라 공간 우위로 싸웁니다. `e4`, `d5`로 중앙을 넓히는 것이 전형적입니다.

## 주요 변형

백이 체크를 막을 수 있는 실질적인 수는 세 가지입니다. `4. Nc3`은 님조인디언의 카스파로프 변형으로 전환되므로, 보고인디언 고유의 변형은 `4. Bd2`와 `4. Nbd2`입니다.

### 4. Bd2 Qe7 (메인 라인)

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Bd2 Qe7`

`4. Bd2`가 가장 흔한 수입니다. 이제 b4 비숍이 공격받으므로 흑은 대응을 정해야 하며, 오늘날 가장 많이 두어지는 수가 `4...Qe7`입니다. 퀸이 비숍을 지키면서 `...e5`를 지원할 준비를 합니다.

`5. g3 Nc6` 이후의 대표 라인은 다음과 같습니다.

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Bd2 Qe7 5. g3 Nc6 6. Nc3 Bxc3 7. Bxc3 Ne4 8. Rc1 O-O 9. Bg2 d6 10. d5 Nd8 11. dxe6 Nxe6`

흑이 `...Ne4`로 c3 비숍을 견제하고, 백이 `d5`로 공간을 얻은 뒤 교환이 이어지며 균형이 맞습니다.

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Bd2 Qe7 5. g3 Nc6 6. Bg2 Bxd2+ 7. Nbxd2 d6 8. O-O a5 9. e4 e5 10. d5 Nb8 11. Ne1 O-O 12. Nd3 Na6`

흑이 비숍을 교환하고 검은 칸에 폰을 고정합니다. 나이트는 a6를 거쳐 c5나 b4로 향하며, 이 포지션도 균형으로 평가됩니다.

### 4. Bd2 a5

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Bd2 a5`

다비드 브론슈타인이 시도한 더 날카로운 수입니다. 비숍을 b4에 유지한 채 퀸사이드 공간을 얻지만, 구조적 약점을 감수합니다.

### 4. Bd2 Bxd2+

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Bd2 Bxd2+ 5. Qxd2`

곧바로 비숍을 교환하는 가장 간단한 방법입니다. 그리 인기 있지는 않지만 스웨덴의 울프 안데르손이 자주 두었고, 무승부를 노리는 라인으로 쓰이기도 했습니다.

### 4. Bd2 c5

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Bd2 c5 5. Bxb4 cxb4`

좀 더 현대적인 라인입니다. 흑 폰이 이중 폰이 되고 중앙에서 멀어지지만, b4 폰은 백 나이트의 c3 칸을 빼앗아 성가신 존재가 됩니다. 그래서 `6. a3`으로 이 폰을 곧바로 교환하는 것이 백의 주요 대안입니다.

### 4. Bd2 Be7

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Bd2 Be7`

비숍을 그냥 물리는 수입니다. 템포를 잃는 것 같지만, 백 비숍이 d2에 어정쩡하게 놓였으므로 흑도 손해가 크지 않습니다. 다소 수동적이지만 견고합니다.

### 4. Nbd2

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Nbd2`

흑 비숍을 나이트와 교환하게 하거나 후퇴시키려는 수입니다. 대신 나이트가 c1 비숍의 길을 막고, d2는 c3보다 덜 활발한 칸입니다. 『갬빗 가이드』는 이 라인을 "야심 찬" 선택이라고 표현했습니다. 흑의 주된 응수는 `4...b6`, `4...O-O`, `4...d5`입니다.

### 4. Nc3

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Nc3`

님조인디언 디펜스의 카스파로프 변형(`1. d4 Nf6 2. c4 e6 3. Nc3 Bb4 4. Nf3`)으로 전환됩니다.

## 함정: 몬티첼리 트랩

보고인디언에서는 몬티첼리 트랩이라 불리는 함정이 나올 수 있습니다. 대표적인 형태는 다음과 같습니다.

수순: `1. d4 Nf6 2. c4 e6 3. Nf3 Bb4+ 4. Bd2 Bxd2+ 5. Qxd2 b6 6. g3 Bb7 7. Bg2 O-O 8. Nc3 Ne4 9. Qc2 Nxc3 10. Ng5`

흑이 `9...Nxc3`로 나이트를 잡으면, `10. Ng5!`가 h7 체크메이트(`Qxh7#`)와 g2 비숍의 b7 비숍 공격을 동시에 위협합니다. 흑은 두 위협을 모두 막을 수 없어 기물을 잃게 됩니다.

## 학습 가이드

1. 먼저 `4. Bd2 Qe7` 메인 라인의 두 가지 전형적 구조(`...Ne4` 형, `...d6–e5` 형)를 익히세요.
2. 보고인디언은 이론 양이 적어, 퀸즈 인디언이나 퀸즈 갬빗 거절을 주로 두는 흑에게 `3. Nf3`에 대한 실전적 대안이 됩니다.
3. 비숍을 교환한 뒤에는 폰을 검은 칸에 두어 남은 흰 칸 비숍과 겹치지 않게 하는 원리를 기억하세요.
4. **백이라면** `g3`·`Bg2` 피앙케토와 `e4`·`d5`로 공간을 넓히는 계획이 기본입니다. 흑은 `...Ne4`나 `...Bxd2+`로 교환을 노리므로, 어떤 기물을 남길지 신중히 고르세요.
5. 몬티첼리 트랩 같은 전술 패턴을 알아 두면, 흑으로 두든 백으로 두든 쉽게 기물을 잃지 않습니다.
